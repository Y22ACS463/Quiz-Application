# Quiz Application

## Project Description
A console-based Quiz Application developed using Core Java. It allows users to answer multiple-choice questions and displays their final score.

## Features
- Multiple-choice questions with four options.
- Accepts answers from users.
- Checks answers automatically.
- Calculates the final score.
- Displays the quiz result.

## Technologies Used
- Java
- Core Java
- OOP Concepts
- ArrayList
- Scanner

## Concepts Implemented
- Classes and Objects
- Constructors
- Encapsulation
- Methods
- Arrays
- Loops and Conditional Statements
- Java Collections

## How to Run
1. Import the project into Eclipse IDE.
2. Open `QuizApplication.java`.
3. Run it as a Java Application.
4. Answer the questions in the Console.
